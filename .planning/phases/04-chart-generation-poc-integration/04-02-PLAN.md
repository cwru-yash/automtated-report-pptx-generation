### 3. Implement ChartGenerator
<read_first>

<action>
Create `app/charts/generator.py` with a `ChartGenerator` class.

The class must use `matplotlib` with the `Agg` backend (non-interactive, safe for server use):
```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
```

Implement these methods, each returning `bytes` (PNG):

**`render_industry_curve(analysis_result: dict) -> bytes`** (Analysis type 1)
- Line chart showing `satisfaction_index` per brand
- X-axis: brand labels (short names); Y-axis: 0–100 satisfaction index
- Horizontal dashed line at `industry_avg`
- Focus brand (`brand-ceragem`) rendered with `COLOR_PRIMARY` and thicker line (lw=2.5)
- Size: `SIZE_WIDE`

**`render_horizontal_bar(analysis_result: dict, color: str, title: str) -> bytes`** (Types 2, 3, 5, 6)
- Horizontal bar chart from `result["links"]` list, sorted by score descending
- Bar labels = `link["label"]`; values = `link["score"]`
- Color coded: pass `COLOR_POSITIVE` for strong links, `COLOR_NEGATIVE` for weak links
- Score annotations on bar ends
- Size: `SIZE_WIDE`

**`render_sr_ranking(analysis_result: dict) -> bytes`** (Analysis type 4)
- Vertical bar chart of brands sorted by composite score
- Focus brand highlighted with `COLOR_ACCENT`
- Size: `SIZE_SQUARE`

**`render_grouped_bar(analysis_result: dict, title: str) -> bytes`** (Types 7, 8)
- Grouped bar chart; for type 8 groups by `segment_value`, for type 7 groups by `brand_id`
- Each group has one bar per brand or activity
- Size: `SIZE_WIDE`

**`render_for_analysis(analysis: dict) -> bytes | None`** — dispatcher method:
- Reads `analysis["analysis_type"]` and `analysis["status"]`
- If `status != "complete"`: returns `None` (skip skipped/failed analyses)
- Routes to the correct render method based on analysis_type:
  - 1 → `render_industry_curve`
  - 2 → `render_horizontal_bar(..., color=COLOR_POSITIVE, title="Strong Links — Industry")`
  - 3 → `render_horizontal_bar(..., color=COLOR_NEGATIVE, title="Weak Links — Industry")`
  - 4 → `render_sr_ranking`
  - 5 → `render_horizontal_bar(..., color=COLOR_POSITIVE, title="Strong Links — Brand")`
  - 6 → `render_horizontal_bar(..., color=COLOR_NEGATIVE, title="Achilles Heel")`
  - 7 → `render_grouped_bar(..., title="Best of Best")`
  - 8 → `render_grouped_bar(..., title="Breakdown")`
  - unknown → `None`

**`render_all(wave_data: dict) -> dict[int, bytes]`** — renders all analyses in wave_data:
- Iterates `wave_data["analyses"]`
- Calls `render_for_analysis` for each
- Returns dict `{analysis_type: png_bytes}` (only completed ones)

Implementation notes:
- Every render method must call `plt.close(fig)` after saving to bytes to prevent memory leaks
- Use `io.BytesIO` to capture PNG bytes: `buf = io.BytesIO(); fig.savefig(buf, format="png", dpi=DPI, bbox_inches="tight"); buf.seek(0); return buf.read()`
- Apply `apply_brand_style(ax)` on every axis before returning
