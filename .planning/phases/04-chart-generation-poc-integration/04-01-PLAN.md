## Goal
Build the `WaveDataProvider` abstraction with a `MockWaveDataProvider` that returns a realistic `wave_data` fixture matching the exact Decomposer schema. Auto-select mock vs real provider based on environment config.

- REQ-13 (partial): Provenance IDs available from wave_data.metadata

### 2. Build WaveDataProvider Abstract Base
<read_first>
- app/config.py
- .planning/phases/04-chart-generation-poc-integration/04-CONTEXT.md
</read_first>
<action>
Create `app/data/__init__.py` (empty init).

Create `app/data/provider.py` with:

1. An abstract base class `WaveDataProvider` with:
   - `@abstractmethod get_wave_data(self, wave_id: str) -> dict` — returns full wave_data blob
   - `@abstractmethod get_latest_wave_id(self) -> str` — returns the most recent wave_id

2. A factory function `get_provider(config: Settings) -> WaveDataProvider` that:
   - Returns `MockWaveDataProvider()` when `config.WAVE_DATA_PROVIDER == "mock"` OR when `config.SUPABASE_URL` is empty
   - Returns `SupabaseWaveDataProvider(config)` otherwise
   - Logs which provider was selected
</action>

- `app/data/provider.py` contains `class WaveDataProvider` with `@abstractmethod`
- `app/data/provider.py` contains `def get_provider(` factory function
</acceptance_criteria>
