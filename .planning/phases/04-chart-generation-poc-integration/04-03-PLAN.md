Create `app/jobs/__init__.py` (empty init).

Create `app/jobs/runner.py` with a `JobRunner` class and a `JobResult` Pydantic model.

**`JobResult` model:**
```python
class JobResult(BaseModel):
    job_id: str
    wave_id: str
    status: str  # "complete" | "failed"
    artifacts: Dict[str, str]  # format → file path, e.g. {"ppt": "output/job_xxx.pptx", "html": "...", "pdf": "..."}
    provenance: Dict[str, str]  # gold_activity_version_id, analysis_run_id
    error: Optional[str] = None
```

**`JobRunner` class:**

`__init__(self, provider: WaveDataProvider, settings: Settings)`:
- Stores the wave data provider and settings
- Initializes `ChartGenerator()`, `HTMLRenderer(settings.TEMPLATES_DIR, settings.LOCALES_DIR)`, `PDFRenderer(html_renderer)`, and `PPTRenderer()`
- Ensures `output/` directory exists (`os.makedirs(settings.OUTPUT_DIR, exist_ok=True)`)

`run(self, template_id: str, language: str, wave_id: Optional[str] = None) -> JobResult`:
- Generate a `job_id = f"job_{uuid4().hex[:8]}"`
- If `wave_id` is None: `wave_id = self.provider.get_latest_wave_id()`
- Fetch `wave_data = self.provider.get_wave_data(wave_id)`
- Extract provenance: `gold_ver_id = wave_data["metadata"]["gold_activity_version_id"]`, `analysis_run_id = wave_data["metadata"]["analysis_run_id"]`
- Build `AnalysisBundle`:
  ```python
  bundle = AnalysisBundle(
      wave_id=wave_id,
      language=language,
      metrics={
          "satisfaction_index": wave_data["quality"].get("weighted_score", 0),
          "briefing_adherence_pct": wave_data["quality"].get("briefing_adherence_pct", 0),
      },
      analysis_results={a["analysis_type"]: a.get("result", {}) for a in wave_data["analyses"] if a.get("status") == "complete"},
      gold_activity_version_id=gold_ver_id,
      analysis_run_id=analysis_run_id,
  )
  ```
- Run narrative engine: `sections = asyncio.run(run_narrative_engine(bundle))`
  Note: use `asyncio.get_event_loop().run_until_complete()` if already in an event loop
- Render charts: `charts = ChartGenerator().render_all(wave_data)` → `Dict[int, bytes]`
- Save chart PNGs temporarily to `output/{job_id}_chart_{type}.png`; collect `images` dict mapping PPT shape names to file paths (e.g. `{"chart_industry_curve": path}`)
- Render HTML: `html_str = self.html_renderer.render(bundle, sections, language=language)`
- Write HTML to `output/{job_id}.html`
- Render PDF (catch ImportError gracefully): write to `output/{job_id}.pdf` or skip if WeasyPrint unavailable
- Render PPT (catch KeyError if template not found): write to `output/{job_id}.pptx` or skip if template_id not registered
- Return `JobResult(job_id=job_id, wave_id=wave_id, status="complete", artifacts={...}, provenance={...})`
- Wrap entire execution in try/except; on failure return `JobResult(status="failed", error=str(e), ...)`
</action>
<acceptance_criteria>
- `app/jobs/runner.py` contains `class JobRunner` and `class JobResult`

- Output files are written to the `OUTPUT_DIR` directory
- Failures are caught and returned as `JobResult(status="failed")` rather than raising exceptions

3. Add a `POST /api/v1/jobs` endpoint:
```python
class JobRequest(BaseModel):
    template_id: str
    language: str = "en-US"
    wave_id: Optional[str] = None

@app.post("/api/v1/jobs")
def create_job(req: JobRequest):
    result = runner.run(req.template_id, req.language, req.wave_id)
    return result.model_dump()
```
