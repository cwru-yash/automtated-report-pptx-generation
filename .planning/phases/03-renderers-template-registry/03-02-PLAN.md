# Phase 3 Plan 02: HTML Renderer

## Goal
Implement a Jinja2-based HTML renderer with two output modes — **branded** (styled, client-facing) and **minimal** (clean, no-frills, good for PDF piping). The renderer reads locale labels from `locales/` and injects narrative sections from the `AnalysisBundle`.

## Requirements Addressed
- REQ-04: HTML renderer produces styled reports using Jinja2 templates
- REQ-06 (partial): Locale label injection supports pt-BR and en-US

## Tasks

### 1. Create Jinja2 Template Files
<read_first>
- app/config.py
- app/bundle/schema.py
</read_first>
<action>
Create the Jinja2 HTML template directory and files at `app/templates/html/`:

**`base.html.j2`** — shared layout, block-based:
```html
<!DOCTYPE html>
<html lang="{{ language }}">
<head>
  <meta charset="UTF-8">
  <title>{{ labels.report_title }} — {{ bundle.wave_id }}</title>
  {% block styles %}{% endblock %}
</head>
<body>
  <header>
    <h1>{{ labels.report_title }}</h1>
    <p class="meta">{{ labels.prepared_by }} | {{ labels.date_format }}</p>
  </header>
  <main>
    {% block content %}{% endblock %}
  </main>
  <footer>
    <p>{{ labels.confidential }}</p>
  </footer>
</body>
</html>
```

**`branded.html.j2`** — extends base, adds rich CSS (dark header, brand colors `#1a2b4a` / `#e8b84b`, Inter font from Google Fonts), renders all sections in styled cards.

**`minimal.html.j2`** — extends base, adds only reset + minimal typography CSS (Arial, 12pt body, black on white), renders sections as plain `<h2>` + `<p>` blocks. Suitable for WeasyPrint PDF piping.

Both templates iterate over `sections` dict in a fixed order: `exec_summary` → `methodology` → `brand_health` → `weak_links` → `takeaways`. Each section is rendered in a `<section>` block with `id="{{ section_key }}"` and heading from `labels[section_key]`.
</action>
<acceptance_criteria>
- `app/templates/html/base.html.j2` exists and contains `{% block content %}`
- `app/templates/html/branded.html.j2` exists and contains `{% extends "base.html.j2" %}`
- `app/templates/html/minimal.html.j2` exists and contains `{% extends "base.html.j2" %}`
- `branded.html.j2` contains `#1a2b4a` (brand color)
</acceptance_criteria>

### 2. Implement HTML Renderer
<read_first>
- app/templates/html/base.html.j2
- app/bundle/schema.py
- app/config.py
</read_first>
<action>
Create `app/renderers/html.py` with:

1. A `HTMLRenderMode` enum: `branded`, `minimal`

2. A `HTMLRenderer` class with:
   - `__init__(self, templates_dir: str, locales_dir: str)` — sets up `jinja2.Environment` with `FileSystemLoader` pointing at `templates_dir/html/`
   - `_load_locale(language: str) -> dict` — reads `{locales_dir}/{language}.json`, returns parsed dict. Falls back to `en-US` if the requested language file is missing, logs a warning.
   - `render(bundle: AnalysisBundle, sections: Dict[str, str], language: str = "en-US", mode: HTMLRenderMode = HTMLRenderMode.branded) -> str`:
     - Loads locale with `_load_locale(language)`
     - Selects template: `"branded.html.j2"` for branded mode, `"minimal.html.j2"` for minimal
     - Renders with context: `bundle=bundle`, `sections=sections`, `labels=locale_dict`, `language=language`
     - Returns the rendered HTML string

3. A `render_html` module-level convenience function.
</action>
<acceptance_criteria>
- `app/renderers/html.py` contains `class HTMLRenderer:`
- `app/renderers/html.py` contains `class HTMLRenderMode`
- `app/renderers/html.py` contains `def render_html(`
- `app/renderers/html.py` imports `jinja2`
- `HTMLRenderer._load_locale` falls back to `en-US` when locale file is missing (verify by reading the code)
</acceptance_criteria>
