### 2. Implement PDF Renderer
<read_first>
- app/renderers/html.py
- app/bundle/schema.py
</read_first>
<action>
Create `app/renderers/pdf.py` with:

1. A `PDFRenderer` class with:
   - `__init__(self, html_renderer: HTMLRenderer)` — stores reference to the HTML renderer
   - `render(bundle: AnalysisBundle, sections: Dict[str, str], language: str = "en-US", output_path: str = None) -> bytes`:
     - Calls `self.html_renderer.render(bundle, sections, language, mode=HTMLRenderMode.minimal)` to get HTML string
     - Passes the HTML string to `weasyprint.HTML(string=html_string).write_pdf()`
     - If `output_path` is provided, writes the PDF bytes to that path and returns the bytes
     - If `output_path` is None, returns the raw PDF bytes
   - Handle `weasyprint` import with a try/except at the top of the file — if WeasyPrint is not available (missing system deps), raise `ImportError` with a helpful message: `"WeasyPrint requires system libraries (pango, cairo). Install with: brew install pango cairo"`

2. A `render_pdf` module-level convenience function.
</action>
<acceptance_criteria>
- `app/renderers/pdf.py` contains `class PDFRenderer:`
- `app/renderers/pdf.py` contains `def render_pdf(`
- `app/renderers/pdf.py` imports `HTMLRenderer` from `app.renderers.html`
- `app/renderers/pdf.py` has a try/except around the weasyprint import with a helpful `ImportError` message
</acceptance_criteria>
