# Phase 3 Plan 01: PPT Renderer & Template Registry

## Goal
Build a Template Registry that maps `template_id` to `.pptx` / HTML template specs with placeholder validation, and implement a PPT renderer that injects narrative content blocks and chart images into named placeholders.

## Requirements Addressed
- REQ-03: PPT renderer fills named placeholders in `.pptx` templates
- REQ-05: Template registry supports multiple templates with placeholder schema definitions

### 2. Build Template Registry
<read_first>
- app/config.py
- app/bundle/schema.py
</read_first>
<action>
Create `app/templates/__init__.py` (empty module init).

Create `app/templates/registry.py` with:

1. A `TemplateType` enum: `ppt`, `html`

2. A `PlaceholderSpec` Pydantic model with fields:
   - `name: str`
   - `type: Literal["text", "image", "number"]`

3. A `TemplateSpec` Pydantic model with fields:
   - `template_id: str`
   - `file_path: str`
   - `template_type: TemplateType`
   - `placeholders: List[PlaceholderSpec]`

4. A `TemplateRegistry` class with:
   - `_registry: Dict[str, TemplateSpec]` (private dict)
   - `register(spec: TemplateSpec) -> None` — adds to registry; raises `ValueError` if template_id already exists
   - `get_template(template_id: str) -> TemplateSpec` — raises `KeyError` with message `"Template not found: {template_id}"` if missing
   - `list_templates() -> List[TemplateSpec]` — returns all registered specs
   - `validate_ppt_placeholders(spec: TemplateSpec) -> None` — opens the .pptx file with `python_pptx.Presentation`, iterates all shapes with `has_text_frame`, collects their `name` attributes, and raises `PlaceholderNotFoundError` for any placeholder in `spec.placeholders` whose name is not found in the slide shapes.

5. A `PlaceholderNotFoundError(Exception)` class.

6. A module-level `registry = TemplateRegistry()` singleton.

7. An `init_registry(templates_dir: str) -> None` function that:
   - Scans `templates_dir` for any `.pptx` files
   - For each file, creates a `TemplateSpec` with `template_id = filename stem` (e.g., `standard_report`), `file_path = full path`, `template_type = TemplateType.ppt`, and `placeholders = []` (schema populated manually or via a sidecar JSON)
   - Calls `registry.register(spec)` for each
   - Logs the count of loaded templates
</action>
<acceptance_criteria>
- `app/templates/registry.py` contains `class TemplateRegistry:`
- `app/templates/registry.py` contains `class PlaceholderNotFoundError(Exception):`
- `app/templates/registry.py` contains `registry = TemplateRegistry()`
- `app/templates/registry.py` contains `def init_registry(`
- `app/templates/registry.py` contains `class TemplateSpec(`
</acceptance_criteria>

### 3. Implement PPT Renderer
<read_first>
- app/templates/registry.py
- app/bundle/schema.py
- app/narrative/graph.py
</read_first>
<action>
Create `app/renderers/__init__.py` (empty module init).

Create `app/renderers/ppt.py` with:

1. A `PPTRenderer` class with method:
   `render(bundle: AnalysisBundle, sections: Dict[str, str], template_id: str, output_path: str) -> str`

   The method must:
   - Call `registry.get_template(template_id)` to retrieve the spec
   - Open the `.pptx` file with `Presentation(spec.file_path)`
   - Iterate all slides and shapes
   - For each shape where `shape.name` matches a key in `sections`, set `shape.text_frame.paragraphs[0].runs[0].text = sections[shape.name]`
   - For image placeholders (type == "image"): if `shape.name` is in a provided `images: Dict[str, str]` dict, use `prs.slides[0].shapes` to add a picture — skip gracefully if the image path is not found
   - Save the presentation to `output_path` with `prs.save(output_path)`
   - Return `output_path`

2. A `render_ppt` module-level convenience function that instantiates `PPTRenderer` and calls `render`.
</action>
