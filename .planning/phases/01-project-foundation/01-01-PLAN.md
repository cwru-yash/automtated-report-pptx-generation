# Phase 1: Project Foundation

## Goal
Scaffold the FastAPI application, set up the directory structure, configure environment variables, and establish connectivity patterns for BigQuery and Supabase.

## Requirements Addressed
- REQ-01 (partial — connectivity only)

<threat_model>
- **Credential Leakage**: Ensure `SUPABASE_KEY` and `GOOGLE_APPLICATION_CREDENTIALS` are read securely via Pydantic Settings and never logged during application startup or connection initialization.
</threat_model>

## Tasks

<task>
<action>
Create the `requirements.txt` file using `pip` as decided in context. Include the following precise packages: `fastapi`, `uvicorn`, `httpx` (for async Supabase calls), `google-cloud-bigquery` (for Decomposer Gold), `pydantic`, `pydantic-settings`. 
Then, create the baseline directory structure: `app/bundle/`, `app/narrative/`, `app/renderers/`, `app/templates/`, and `app/core/`.
</action>

- .planning/phases/01-project-foundation/01-CONTEXT.md
</read_first>
<acceptance_criteria>
- `requirements.txt` contains `fastapi`, `httpx`, and `google-cloud-bigquery`
- Directories `app/templates/` and `app/core/` exist
</acceptance_criteria>
</task>

<task>
<action>
Create `.env.example` and `app/config.py`. 
In `.env.example`, define empty keys for: `GOOGLE_APPLICATION_CREDENTIALS`, `SUPABASE_URL`, and `SUPABASE_KEY`.
In `app/config.py`, create a `Settings` class using `pydantic_settings.BaseSettings` that loads these three variables, and export a globally accessible `settings` instance.
</action>

</task>

Include a startup event that safely logs the successful initialization of settings without printing secrets.
</action>

<task>
<action>
Implement the connectivity stubs in `app/core/`.

2. Create `app/core/supabase.py` with an async class `SupabaseRESTClient`. It should instantiate an `httpx.AsyncClient` with `Authorization: Bearer <SUPABASE_KEY>` and `apikey: <SUPABASE_KEY>` headers, targeting `SUPABASE_URL`.
